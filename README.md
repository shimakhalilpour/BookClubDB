# Online Bookstore Database

## Overview
A relational database designed for an online bookstore system using SQL Server.
The project focuses on database design principles, normalization, data integrity, and efficient relationship management between entities.

## Features
- User and Role Management
- Publisher Management
- Book Catalog Management
- Shopping Cart
- Wishlist
- Order Processing
- Notification System
- Discount Management

## Database Design Highlights
- Normalized database structure
- Primary Key and Foreign Key relationships
- Data integrity constraints
- Default and Check constraints
- Scalable relational schema
- Support for future expansion

## Technologies
- Microsoft SQL Server
- T-SQL

## Main Entities
- Users
- Roles
- Publishers
- Books
- Orders
- OrderItems
- ShoppingCart
- Wishlist
- Notifications
- Discounts

The repository includes an Entity Relationship Diagram (ERD) illustrating the database structure and table relationships.
